# 10단계 — 게임 조작과 요청 중 입력 제어

`GameClientRoot`는 서버 변경 요청 동안 HUD 전체 입력을 비활성화하고 완료 콜백에서 다시
활성화합니다. 따라서 더블 탭이나 빠른 연속 선택이 동일 revision의 변경 요청을 병렬로
발행하지 않습니다. 빈 슬롯은 생성 의도, 아이템 두 슬롯은 머지 의도로 처리하며 서버
응답 전에 보드·재화·revision을 낙관적으로 바꾸지 않습니다. 409는 최신 상태와 안내를
표시해 사용자가 다시 선택하도록 합니다.

Unity 전체 검증은 컴파일 오류/경고 0, EditMode 13개와 PlayMode 11개 통과 기준입니다.
